# Отклик - Приложение для найма, поиска сотрудников и отклика на вакансии
## Описание

Отклик - это современное веб-приложение для удобного найма и отклика на вакансии. Проект состоит из двух частей:

1. **Фронтенд** - React-приложение с использованием современных технологий
2. **Бэкенд** - серверная часть на Node.js с Express и Sequelize

## 🛠 Технологии

### Фронтенд
- `React 19` + `Vite`
- `Redux Toolkit` + `React-Redux`
- `React Router v7`
- `Tailwind CSS` с плагинами
- `Framer Motion` для анимаций
- `ESLint` + `Prettier` для линтинга

### Бэкенд
- `Node.js` + `Express`
- `Sequelize ORM` (PostgreSQL)
- `Express Session` + `CORS`
- `Cookie-parser` + `JWT`
- `Sequelize CLI` для миграций

## 🚀 Установка и запуск

### Frontend (папка `ot_click/frontend`)
```bash
cd frontend
npm install
npm dev # режим разработки
npm build # сборка для продакшена
```

### Backend (папка `ot_click/backend`)
```bash
cd backend
npm install
npm dev 
```
